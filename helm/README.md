## Installation

```bash

```

### Install the Chart

```bash

  --namespace <namespace> \
  --create-namespace
```

You can also install directly from a chart repository:


## Configuration

The chart is highly configurable via the **`values.yaml`** file. Override defaults by providing your own values file or using `--set` flags.

### Using a Custom Values File

```bash
helm upgrade --install <release-name> ./helm \
  -f my-values.yaml \
  --namespace <namespace>
```

### Commonly Overridden Values

| Parameter | Description | Default |
|-----------|-------------|---------|
| `replicaCount` | Number of pod replicas | `1` |
| `image.repository` | Container image repository | `myrepo/myapp` |
| `image.tag` | Container image tag | `"{{ .Chart.AppVersion }}"` |
| `service.type` | Service type (`ClusterIP`, `NodePort`, `LoadBalancer`) | `ClusterIP` |
| `resources.limits.cpu` | CPU limit for the pod | `"500m"` |
| `resources.limits.memory` | Memory limit for the pod | `"256Mi"` |
| `ingress.enabled` | Enable Ingress resource | `false` |
| `ingress.hosts[0].host` | Hostname for Ingress | `"chart.example.com"` |

> **Note:** Update the values to match your environment and operational requirements.

## Upgrading

When a new chart version is released, upgrade your release with:

```bash

  -f my-values.yaml \
  --namespace <namespace>
```

For versioned releases, specify the chart version:

```bash
helm upgrade <release-name> ./helm --version 1.2.3
```
